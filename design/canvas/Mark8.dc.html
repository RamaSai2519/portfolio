mark8 · realtime call analyst

Every support call, read and scored as it happens.

Sukoon's experts talk to seniors on the phone all day. mark8 reads each call against the service's guidelines, tags what it was about, keeps a persona for both sides, and scores the conversation, so the team sees quality without listening to every call.

03 — the server around it

One process, Flask and Quart side by side

Starlette mounts a sync Flask app and an async Quart app together. Besides scoring calls, the same server ran Sukoon's operations: bulk users and schedules, WhatsApp queues, push notifications and PDF invoices.
